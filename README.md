# Macropad
A Marcopad with 6 keys, a rotary encoder and 4 SK6812 LEDs. It uses a rp2040 and has a KMK firmware.

<img width="1013" height="661" alt="Screenshot 2025-12-07 195944" src="https://github.com/user-attachments/assets/82af53d1-fcc8-4c17-987e-43ecc6f5cc77" />

It is designed to make desktop and window mangement in Windows easier.

## Features:
- A simple case, that shows off the PCB and Components.
- EC11 Rotary 
- 4 SK6812 RGB LEDs. They just look good
- 6 Keys, for any Marcos

## BOM
What you need except for the Case, PCB and Firmware

- 6x Cherry MX Switches
- 6x DSA Keycaps
- 1x EC11 Rotary Encoder
- 1x XIAO RP2040
- 4x SK6812 LEDs
